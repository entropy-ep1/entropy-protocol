The eServer 325 server, which is priced at US$2,199, is based on AMDs dual-core Opteron processor, and the Cluster 1350 can scale to as many as 32 servers. The bundle includes a copy of IBM's Tivoli Systems Director, which allows customers to manage the servers from a central point. It also comes with 600GB of IBM's DS4000 storage, which is designed to run both Windows and Linux. The IBM cluster can be used in environments that run scientific and technical computing applications, such as molecular dynamics, molecular docking, computational chemistry, financial modeling, and weather forecasting. The system can also be used in data analytics applications, such as bioinformatics, genomic analysis, and enterprise data warehousing, IBM said. The new offering is similar to other cluster packages that IBM and other vendors have announced in recent months. IBM on Sept. 26 announced a cluster based on its eServer 335 server, which uses 64-bit Itanium 2 processors, and on Nov. 3 it announced a cluster based on its Power 5 servers. Dell Inc. and Hewlett-Packard Co. also offer prepackaged clusters. IBM's latest offering is a good value for technical and scientific computing, said Jack Vaughan, an analyst at Directions on Microsoft. "The price point is about $67,000 for a 16-node cluster, which is a good value for technical and scientific computing," he said. "That is a pretty good value compared to other options on the market." But some potential customers may be turned off by the lack of support for the 32-bit version of Windows, said Richard Doherty, research director at Envisioneering Group.
